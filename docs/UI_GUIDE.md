# lazycat-search UI Guide

> 最后更新：2026-08-23
> 当前依据：`懒猫搜索 PRD.md`、`docs/DESIGN.md` 与 Next.js 门户源码。`lazycat_search_portal.html` 保留为历史交互原型，Next.js 门户按其应用框架和信息组织还原，并接入本地服务。

## 全局规则

- 登录后采用原型中的顶栏加左侧导航的管理控制台布局。桌面端侧栏宽 240px，包含联网搜索、MCP 服务、引擎管理、统计审计、系统配置；当前页面使用蓝色描边高亮。
- 顶栏展示项目名、中文/英文切换、管理员会话和登出操作。中英文切换属于 V1 范围；新增页面文案应同时维护两种语言。
- Next.js 门户使用浅色背景、蓝色主操作、卡片式内容区和状态徽标。基础组件位于 `src/components/ui/`，包括 Button、Input、SearchInput、Tag、Tabs、Switch、Select、Modal、Toast。
- 使用键盘操作时，登录和搜索表单都应支持 Enter 提交；弹窗须提供关闭按钮和可见焦点。小于 768px 时侧栏收缩为图标栏，搜索表单自动换行，宽表格保留容器内横向滚动。

## 页面与关键状态

### Login

- 组件：管理员用户名、密码、提交按钮与服务端返回的登录错误提示。
- 不得预填真实或可用的管理员密码。密码使用占位提示，登录调用本地管理员会话 API。

### Search

- 组件：搜索输入、URL 正文读取提示、引擎多选、恢复默认、结果数量、Bing 高级选项、结果列表、部分失败横幅、正文阅读、搜索历史。
- 结果条目展示标题、URL、域名、描述和来源引擎；操作包括打开原网页与读取正文。
- 正文阅读展示标题、原始 URL、最终 URL、Content-Type、截断状态和正文；提供复制正文与打开源站。
- 空结果、部分引擎失败和请求失败均由实际 API 响应显示；原型保留的状态选择器仅改变当前页的预览提示，不会伪造或写入服务端搜索结果。

### MCP

- 组件：Endpoint、Transport、运行状态、Tool 列表、Token 列表、新建 Token、客户端配置模板、管理 API 检查。该检查读取实际管理端元数据与 Tool 声明，不替代带 Token 的 MCP initialize 调用。
- Token 创建后完整 Secret 只展示一次；列表显示名称、Prefix、Scope、配额、过期时间、最近使用时间和状态。

### Engines、Usage 与 Settings

- Engines：显示名称、启用、默认、Search Mode、最近测试时间、状态、延迟、最近错误；提供单引擎测试。
- Usage：显示 Web/MCP 调用量、成功率、缓存命中率、平均响应时间、引擎统计和包含 PRD 字段的请求日志。
- Settings：代理、搜索/正文缓存、限流、默认引擎与数量、搜索历史和 MCP Query 日志。含密码的代理地址必须脱敏；“测试代理”在当前本地运行时只校验 URL 格式，并明确提示没有独立探测接口。

## 数据与安全边界

- 搜索、正文读取、引擎状态、Token、设置、历史与审计均调用本地 Fastify API；开发环境由 Next rewrite 提供同源路径。
- React JSX 默认以文本节点呈现搜索结果、日志和正文，不使用 `innerHTML`。
- V1 不展示或实现 Playwright 控件；Bing 的原型界面保留 Auto / Request 选项，实际请求一律使用安全的 Request 模式。
