# DEC-20260824-006 搜索历史永久保存

## 状态

已确认实施。用户要求“搜索历史保留天数支持永久保存”。

## 方案

- 继续复用现有 `history.retentionDays` 数值设置，不新增数据库字段或迁移。
- `-1` 表示永久保存；正整数继续表示保留天数，范围为 1–3650 天。
- 设置页提供“永久保存 / Forever”选项，并将选择持久化到 `/api/settings`。
- 历史清理在修改设置、读取历史和写入新历史时执行；选择 `0` 时跳过删除，手动“清空历史”仍然有效。
- 既有数据库中的 30/90 等数值继续兼容，默认值仍为 30 天。

## 边界

- 永久保存只针对 `search_history`，不改变请求审计日志的保留策略。
- 不保存网页正文以外的额外数据；历史快照仍遵循现有结果快照结构。
