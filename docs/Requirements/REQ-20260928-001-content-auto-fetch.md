# REQ-20260928-001 内容抓取自动匹配与状态颜色

## 状态

实现完成；本轮补充的来源标签样式与通用网页回退待回归验证。Linux.do 可访问网络和目标设备验证仍待执行。关联决策：`DEC-20260928-001`。

## 范围

- 引擎排序列表的已启用、已停用状态文字分别显示为绿、红色；英文同步。
- 内容抓取页支持小红书、飞书、CSDN、掘金、Linux.do、GitHub 仓库 README 和普通网页。用户粘贴链接或分享文案后自动匹配，无需选择来源。
- 来源标签复用首页 `EngineTag` 尺寸、图标布局和来源色板，保留中英文名称。
- 抓取结果在同一页面预览，并可下载与预览一致的 Markdown。

## 数据流与边界

- 页面从分享文案提取 URL，调用现有 `/api/fetch-content` 并启用自动匹配。小红书、飞书复用平台抓取；四个站点复用现有站点专用抓取；没有命中专用来源与路径的 URL 使用通用网页正文抓取。未启用自动匹配的其他调用保留原行为。
- 服务端按无凭据 HTTP(S) URL 校验，专用匹配限制 HTTPS、精确主机和内容路径。Linux.do 常见 `/t/<slug>/<id>` 地址转换为现有上游支持的 `/t/topic/<id>.json`，预览和下载保留输入地址。
- 结果只在页面状态及既有正文缓存中保留。刷新后重新提交；失败显示错误，不保存空正文。保持会话鉴权、限流、审计、最大长度、媒体校验与 Token 边界。
- 搜索页正文阅读器、MCP 通用正文工具、飞书连接、搜索和历史行为保持原状。

## 验收

| 场景 | 结果 |
|---|---|
| 小红书与飞书内容链接 | 使用平台抓取，图片仍在预览中显示，下载包含已有图片 Markdown 链接 |
| CSDN、掘金文章 | 命中对应专用抓取器并可预览、下载 |
| Linux.do 主题链接 | `/t/<slug>/<id>` 与 `/topic/<id>` 命中专用抓取器 |
| GitHub 仓库链接 | 抓取默认分支 README；Issues 等其他路径不误匹配 |
| 普通网页与伪装主机 | 走通用正文抓取 |
| 不支持的来源或未命中专用路径 | 内容页回退到通用网页正文抓取 |
| 启用状态与语言切换 | 中文、英文的启用状态均为绿色，停用状态均为红色 |
| 来源标签 | 内容页标签与首页共用 EngineTag 尺寸、图标布局和对应色板 |
