# REQ-20260825-009 门户持久化与 PRD 对齐审查、Usage UI 收口

## 目标

梳理 Login、Search、MCP、Engines、Usage、Settings 及全局状态的持久化边界，核对 `docs/喵喵搜索 PRD.md` 的页面/功能口径，并收口门户文案与布局：修复 Usage 审计表横向滚动位置、统计 KPI 卡片布局、统计范围下拉遮挡、DuckDuckGo 引擎 Tag 图标加载问题，统一审计筛选与表格国际化，将引擎贡献改为引擎统计，并移除 Settings 的默认搜索参数 Card。

## 范围与边界

- 只记录已有页面状态、服务端写入入口和当前可验证的功能，不把临时 React state 描述为持久化能力。
- 本轮不新增数据库表、不改变 API 数据语义、不接入真实外部 MCP 客户端，也不绕过上游反爬或代理限制。
- PRD 与当前 OIDC、首页偏好持久化、外部部署验证之间的差异记录在 `docs/PORTAL_REVIEW_20260825.md`，待产品决定后再改 PRD 或实现。

## 验收矩阵

| 场景 | 验收 |
|---|---|
| 持久化边界 | 审查记录逐页列出变量、存储位置、写入时机和刷新后的行为。 |
| Usage 横向滚动 | 筛选器、审计表和分页在同一滚动容器，滚动条位于卡片底部。 |
| Usage KPI | 桌面端最多四列，卡片不再压缩为七列；中小屏保持响应式列数。 |
| DuckDuckGo 图标 | Tag 使用稳定官方资源；图片失败时仍显示 Globe fallback，不影响名称和语义。 |
| Bing 高级选项 | 只有当前选择包含 Bing 时显示 Search Mode，其他引擎场景不展示无效配置。 |
| Usage 文案与筛选 | 引擎区标题为“引擎统计”；审计筛选器、表头、状态和缓存命中状态按当前语言显示，不出现中文模式混入英文业务文案。 |
| Usage 范围下拉 | 统计范围菜单不被 Usage hero Card 的装饰层或溢出裁剪。 |
| Settings | 页面不再渲染“默认搜索参数” Card；默认返回数和引擎默认项仍由各自实际设置入口负责。 |
| 回归 | `pnpm typecheck`、`pnpm lint`、`pnpm test`、`pnpm build` 通过。 |

## 未纳入本轮实现的 PRD 缺口

- Settings 每引擎独立速率和正文最大长度控件尚未实现。
- 懒猫设备、真实 OIDC 和外部 MCP 客户端回归仍属于阶段 4。
