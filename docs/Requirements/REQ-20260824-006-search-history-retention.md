# REQ-20260824-006 搜索历史永久保存

## 目标

系统设置中的搜索历史保留期支持“永久保存”，并在前后端持久化后真正影响历史清理。

## 范围与语义

- `history.retentionDays` 继续使用现有数值设置；`-1` 表示永久保存，1–3650 表示保留天数。
- 设置页中英文均提供 Forever / 永久保存选项。
- 修改设置、读取历史和写入新历史时按当前保留期清理；永久保存跳过自动删除。
- 手动清空历史不受永久保存影响，仍立即删除全部搜索历史。
- 不修改 SQLite 表结构，不影响请求审计日志或 MCP Token 数据。

## 验收矩阵

| 场景 | 预期 |
|---|---|
| 选择“永久保存”并保存 | `/api/settings` 返回 `historyRetentionDays: -1`，刷新页面仍为永久保存 |
| 永久保存后读取历史 | 既有历史记录不因自动清理删除 |
| 选择 30 天 | 超过 30 天的历史记录在设置更新、读取历史或新增搜索时清理 |
| 手动清空历史 | 无论保留期为何值，全部历史立即清空 |
