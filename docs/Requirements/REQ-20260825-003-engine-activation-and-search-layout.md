# REQ-20260825-003：搜索引擎启用前置校验与首页结果布局

## 状态

进行中。用户于 2026-08-25 确认按 `docs/Decisions/DEC-20260825-003-engine-activation-requirements.md` 实施。

## 范围

- 移除 Brave，不再出现在可选引擎、默认配置、引擎管理、首页筛选、结果来源、统计样例和新的数据库引擎行中。
- 对 Exa 的 API Key、需要代理的引擎执行服务端启用前校验；失败时返回明确错误，前端消息提示且开关保持关闭。
- 引擎管理页通过弹窗配置或清除 API Key；服务端加密保存，只返回是否已配置。
- 首页搜索筛选与结果区按“先筛选、再结果总览、最后引擎分组/聚合”的层级重排；引擎 Tag 在首页、引擎管理、结果、历史、统计中统一，均带官方图标。

## 数据与写入入口

- 复用 `setting` 表写入 `engine.<id>.apiKey`，通过 `SettingsService` 加密；不新增明文字段。
- `PATCH /api/engines/:id` 接受 `apiKey` 仅用于配置弹窗；`GET /api/engines` 只返回 `apiKeyConfigured` 与引擎前置条件元数据。
- Brave 通过新迁移删除数据库引擎行；历史记录和审计原文不回写、不篡改。

## 读取、刷新与恢复

- 门户登录刷新时读取引擎配置；保存 API Key 后刷新引擎列表，弹窗关闭并提示重启独立 Open-WebSearch daemon。
- 启用失败不更新数据库；页面保留关闭状态。清除 Exa Key 后，已启用状态不自动改变，但下一次启用或测试按缺少 Key 处理。
- 迁移失败阻止服务启动，保留迁移前数据库；不执行 destructive reset。

## 验收矩阵

| 场景 | 预期 |
|---|---|
| Brave 出现在 API 请求、类型、首页或管理页 | 不出现；数据库迁移后不再有新的 Brave 引擎行 |
| 启用需要代理的引擎但代理关闭、为空或 URL 非 HTTP(S) | 400，返回代理配置错误；开关不改变 |
| 启用 Exa 但没有 API Key | 400，返回 API Key 配置错误；开关不改变 |
| API Key 保存后读取引擎列表 | 只看到 `apiKeyConfigured=true`，响应不含明文 |
| API Key 配置弹窗清除 | 服务端删除加密值，提示 daemon 重启；不显示旧密钥 |
| 首页与引擎管理 Tag | 同一颜色、圆角、边框和官方图标；图标失败仍有文本 |
| 首页搜索布局 | 输入、引擎筛选、请求选项、结果总览、失败反馈、分组/聚合结果在桌面和移动端可用；不改变搜索 API 语义 |

## 不受影响模块

正文 SSRF、Token 鉴权、MCP Tool 语义、搜索结果安全转义、现有代理地址脱敏和历史快照结构不改变。
