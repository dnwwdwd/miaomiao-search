# REQ-20260825-011：MCP Token 限额选项与复制

## 状态

已完成。MCP 管理页的新建 Token 表单支持每分钟和每日限额的无限制选项，也保留手动输入；Token Secret 弹窗提供一键复制。

## 范围

- 每分钟限流和每日调用上限分别提供“无限制”开关与数字输入。
- 手动输入沿用服务端边界：每分钟 1–10,000 次，每日 1–1,000,000 次，必须是整数。
- 选择无限制时向已有 `POST /api/tokens` 发送 `null`，服务端继续按 `null` 不设上限处理。
- `/api/tokens` 的 `null` 限额在门户类型和读取映射中保留，列表显示“无限制”。
- Token 创建成功后，Secret 弹窗提供独立的“复制 Token”按钮；Secret 仍只在创建响应和当前弹窗中展示一次。

## 非目标

- 不新增或修改 SQLite schema、迁移、限流算法、MCP Tool、Endpoint 或认证策略。
- 不把 Token Secret 写入本地存储、日志或持久化数据。

## 数据与失败边界

| 场景 | 写入 / 展示 | 预期 |
|---|---|---|
| 限额为手动值 | `rpmLimit` / `dailyLimit` 为整数 | 服务端按对应窗口限制调用 |
| 限额为无限制 | 对应字段为 `null` | 服务端不执行该窗口的限流判断，列表显示“无限制” |
| 手动值为空、非整数或超范围 | 不发起创建请求 | 页面提示对应字段错误 |
| Secret 复制成功 | 浏览器剪贴板写入完整 Secret | 弹窗保留，显示“已复制到剪贴板”提示 |
| 剪贴板不可用 | 不改变 Secret 展示 | 页面提示剪贴板权限不可用，用户仍可手动复制 |

## 验收矩阵

| 场景 | 验收结果 |
|---|---|
| 仅每分钟限额无限制 | 创建请求的 `rpmLimit` 为 `null`，每日限额保留手动值 |
| 仅每日上限无限制 | 创建请求的 `dailyLimit` 为 `null`，每分钟限额保留手动值 |
| 两项都无限制 | 两个字段均为 `null`，Token 创建成功 |
| 两项都手动输入 | 合法整数可创建，列表显示对应数值 |
| Secret 一键复制 | 点击复制按钮调用剪贴板写入完整 Secret，并显示成功提示 |
| 中英文切换 | 限额、无限制、校验、复制和失败提示均有中英文文案 |
