# REQ-20260825-002 移除 Startpage 与搜索结果 JSON 展示

## 状态

已完成。

## 目标

移除不可用的 Startpage 搜索引擎源；首页结果卡片显示结果网站图标，并提供可复制、可检查的嵌套 JSON 响应视图；MCP `search` 继续向外暴露 JSON 文本和同结构的结构化响应。

## 已确认规则

- Startpage 从服务端引擎枚举、管理页、首页选择器、示例数据和文案中移除。
- 数据库迁移删除旧的 Startpage 引擎配置，并将已保存的首页引擎选择重置为空数组，使其回退到当前默认引擎；历史搜索快照和审计记录不删除。
- 搜索结果新增可选 `faviconUrl`。服务端只根据已校验的 HTTP(S) 结果 URL 生成 `<origin>/favicon.ico`，不抓取或代理第三方图标；首页加载失败时显示通用图标，旧历史快照没有该字段时由首页同样回退生成。
- 首页 JSON 查看器展示当前搜索响应的嵌套 `engineResults[].results[]`、聚合 `results`、失败信息、缓存状态和总数，不改变 API 数据。
- JSON 查看器提供一键复制，复制成功显示短暂状态反馈；采用浅色工作台、深色代码面板和底部操作区，桌面及 375px 窄屏保持可滚动和可操作。
- MCP `search` 的文本 `content[0].text` 是 `JSON.stringify(result)`；`structuredContent` 返回同一份嵌套对象，保留 `engineResults` 与兼容的 `results`。

## 验收矩阵

| 场景 | 验收 |
|---|---|
| Startpage 移除 | 新数据库不创建 Startpage；旧数据库迁移后无可配置的 Startpage，历史记录仍可读取 |
| 网站图标 | 分组和聚合结果卡片显示网站图标；图标请求失败不影响结果阅读 |
| JSON 查看 | 首页搜索成功或部分成功后可打开 JSON，分组结果嵌套且与页面当前响应一致 |
| JSON 操作 | “复制 JSON”可写入剪贴板并显示“已复制”；剪贴板不可用时显示错误提示，不能影响弹窗关闭 |
| MCP 兼容 | 文本 JSON 和结构化响应均可解析，旧的平铺 `results` 仍存在 |
| 安全边界 | 不新增 favicon 代理、任意 URL 抓取或跨域读操作，不弱化既有 SSRF/XSS 防护 |
