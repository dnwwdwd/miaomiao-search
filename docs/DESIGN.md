# lazycat-search 前端设计说明

> 适用于 Next.js 门户实现；保留原静态原型的管理控制台风格。

## 1. 视觉主题与氛围

界面是“清晰、克制、可信”的浅色管理控制台：淡蓝灰工作区、白色内容面、蓝色操作色。它优先让搜索、配置和状态信息易于扫读，不使用营销页式大标题或装饰背景。

## 2. 色彩与角色

| Token | 值 | 用途 |
|---|---|---|
| `canvas` | `oklch(0.975 0.006 250)` | 页面背景 |
| `sidebar` | `oklch(0.955 0.012 250)` | 侧边栏与次级表面 |
| `surface` | `oklch(1 0 0)` | 卡片、表格、弹窗 |
| `ink` | `oklch(0.23 0.025 255)` | 主文字 |
| `muted` | `oklch(0.52 0.025 255)` | 辅助文字 |
| `accent` | `oklch(0.57 0.18 250)` | 主按钮、选中、链接 |
| `success` / `warn` / `danger` | `oklch(0.58 0.15 150)` / `oklch(0.72 0.16 75)` / `oklch(0.58 0.2 28)` | 状态反馈 |

## 3. 字体规则

为与历史原型一致，使用 `Plus Jakarta Sans` 作为界面字体、`JetBrains Mono` 作为数据与代码字体；二者由原型相同的 Google Fonts 地址加载。页面标题 24px/700/-0.012em，区块标题 14px/700，正文 13px/1.6，数据表与 Token 使用等宽数字。图标由与原型相同的 Phosphor Web CDN 加载。

## 4. 组件样式

- Button：8px 圆角，至少 40px 点击面积；主按钮使用 `accent`，按下缩放到 0.96。
- Input / SearchInput：8px 圆角、浅色填充、蓝色可见焦点环；错误时使用 `danger` 描边。
- Tag：胶囊形，仅用于引擎来源、状态和 Scope；不用于普通操作。
- Tabs：有语义的 `button`，底部短线和颜色表达选中状态。
- Card：12px 圆角，轻微阴影区分于画布；表格用分隔线而非层层卡片。
- Modal：只用于需要集中确认的 Token 创建与引擎测试；可通过关闭按钮和 Escape 关闭。

## 5. 布局原则

桌面端为 232px 左侧导航与可滚动主工作区；内容最大宽度 1024px。顶栏使用白底、项目标记、语言选择、管理员状态和登出操作；使用 4/8/12/16/24/32px 间距，不在数据页面插入横幅式介绍区域。

## 6. 层级与深度

画布、侧栏、卡片三层用亮度和 1–2 级轻阴影区分；卡片与表格边界使用半透明描边。圆角只使用 8px、12px、16px 和 pill 四档。

## 7. 约束

- 不使用渐变文字、玻璃模糊、厚色边栏或无意义插图。
- 不用 `transition: all`，只过渡颜色、透明度和变换。
- 不把模拟数据、模拟 Token 或模拟连接测试说成真实服务状态。
- 所有图标按钮提供 `aria-label`，状态颜色之外还必须有文字。
- 正文和日志只走 React 文本节点，不使用不安全 HTML 注入。

## 8. 响应式行为

小于 768px 时导航折叠为 68px 图标栏；小于 640px 时表格允许横向滚动、表单改为单列。触摸控件最小 40px，使用 `prefers-reduced-motion` 降低动效。

## 9. 后续组件提示

- 创建 Settings 开关：卡片背景 `oklch(1 0 0)`，12px 圆角，文字 `oklch(0.23 0.025 255)`，选中轨道 `oklch(0.57 0.18 250)`。
- 创建状态 Tag：pill 圆角，12px/700，颜色同时搭配图标或状态文字。
- 创建搜索结果：表格式列表而非瀑布卡片，标题 14px/700，URL 使用等宽 12px，来源使用 Tag。
