# DEC-20260825-010：MCP 百度搜索 302 重定向处理

## 状态

已实施。用户反馈首页使用 Baidu 可以成功搜索，但 MCP 搜索返回“302 重定向错误”。

## 决定

- Open-WebSearch 的 Baidu 适配器在未配置代理时使用 Node 原生 `fetch`，关闭自动重定向并在代码中逐跳处理响应。
- 最多允许 3 次重定向；目标必须是 HTTPS 的 `baidu.com` 或其子域名，其他协议和主机直接失败，保留 SSRF 与未知主机重定向的安全边界。
- 配置代理时继续使用现有 Axios 代理通道，避免改变代理环境下的请求路径。
- Baidu 请求统一使用稳定的搜索参数和浏览器请求头，减少因请求条件差异触发 302 验证页的概率。
- 补丁随 `open-websearch@2.1.11` 固化到 pnpm 安装和 LPK 构建流程，MCP 与首页共用同一 daemon 适配器。

## 验收

1. `lazycat`、`喵喵搜索`、`MCP服务`、`百度搜索` 通过本地 daemon 的 Baidu 引擎返回结果。
2. 源码契约测试检查 Baidu 手动重定向和主机白名单逻辑。
3. 安装、类型检查、lint、单元/契约测试、生产构建和 LPK lint 通过后，重新生成发布包。
