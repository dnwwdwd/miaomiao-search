# DEC-20260825-002 移除 Startpage 与搜索结果 JSON 兼容策略

## 决策

1. Startpage 作为运行时可选搜索引擎移除。通过数据库迁移删除旧配置，并将首页引擎偏好重置为空数组；历史快照和审计日志保留为历史事实，不做清理。
2. 网站图标使用结果 URL 的 origin 拼接 `/favicon.ico`。服务端不会主动请求图标，首页使用原生懒加载并在失败时回退到通用图标，避免新增图标代理和 SSRF 面。
3. 首页 JSON 查看器直接序列化当前已收到的搜索响应，保持 `engineResults` 分组嵌套与 `results` 聚合兼容视图同时可见。
4. MCP `search` 不改变传输协议：文本内容是 JSON 字符串，`structuredContent` 是相同对象；两者都包含分组结果和旧平铺结果。

## 理由与影响

Startpage 已在本地上游验证为反爬错误，继续展示会造成可选源与实际能力不一致。图标采用派生 URL 而非服务器抓取，功能足够且不扩大安全边界。MCP 保留双形态可避免旧客户端只读取 `results` 时产生兼容性回归。

## 验证

- 迁移测试确认 Startpage 行被删除，旧历史读取路径不依赖该引擎枚举。
- 源码契约测试确认 MCP 文本 JSON 与 `structuredContent` 使用同一响应对象。
- 首页类型检查和构建需在本次改动后执行；真实上游图标是否存在由浏览器加载失败回退处理。
