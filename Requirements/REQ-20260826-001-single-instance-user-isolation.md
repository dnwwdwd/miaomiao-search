# REQ-20260826-001：单实例懒猫用户隔离与会话切换

## 状态

已实施，等待懒猫设备验证。

## 目标

应用改为单实例运行，由应用内部维护懒猫网关 UID、OIDC sub 和本地账号的映射，并为每个懒猫用户提供独立业务数据空间。

## 范围与行为

- lzc-manifest.yml 不再声明 multi_instance，实例密钥使用安装级稳定种子。
- 身份库保存网关 UID、OIDC sub、本地账号、角色、密码哈希和 Token 归属索引。
- 用户业务库按网关 UID 的 SHA-256 目录分隔，保存引擎、设置、历史、审计、缓存和 Token 数据。
- OIDC 和本地登录都必须绑定当前 X-HC-User-ID；生产请求缺少 UID 时认证失败。
- 会话 Cookie 保存网关 UID 与 owner，当前请求 UID 变化时清除会话并返回认证错误。
- MCP Token 绑定 owner；外部 MCP 请求可只凭 Token 定位用户库，同时携带网关 UID 时必须匹配。
- 原多实例 LPK 生成的数据库不迁移、不读取。

## 验收

1. 两个懒猫 UID 的设置、引擎、历史、审计和 Token 互不可见。
2. UID 切换后，旧 Cookie 的受保护 API 返回会话失效，前端自动回到 / 登录页。
3. 本地账号只能在绑定 UID 下登录；OIDC sub 与 UID 冲突时拒绝重新绑定。
4. MCP Token 只能访问其 owner 数据；Token 状态、限额和审计仍正常工作。
5. 登出清除 Cookie 并回到根路径，不进入 404 页面。
