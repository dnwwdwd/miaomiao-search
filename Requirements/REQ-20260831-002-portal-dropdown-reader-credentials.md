# REQ-20260831-002：门户下拉层、正文阅读器与凭据交互收口

## 背景与范围

本需求收口门户在表格滚动、正文阅读、凭据配置和首页来源选择中的交互问题，并补充 B 站结果的专用展示。范围包括 Next.js 门户、共享 Dropdown、引擎目录/管理 API、B站 Provider 与历史快照兼容；不改变搜索鉴权、限流、正文 SSRF/XSS 边界或 MCP Tool 名称。

## 已确认行为

- 所有 Dropdown 菜单使用 `body` 浮层和按钮视口坐标定位，滚动或调整窗口时同步更新；菜单支持原有键盘、点击外部关闭和 listbox 语义。
- 正文阅读器内容区保留蓝色边框并增加圆角。B站结果不调用通用正文抓取，使用搜索返回的封面和可用视频元数据展示详情；详情只提供打开源站，不提供复制正文。
- Exa、Firecrawl、Tavily 和 GitHub 的凭据弹窗展示对应官网申请链接，链接高亮并在新窗口打开；输入值支持明文/脱敏切换，服务端仍只保存加密凭据。
- 首页来源至少保留一个选中引擎。取消唯一来源时提示用户，不自动改选全部已启用来源。引擎管理的凭据 Tag 显示“点击修改 / click to edit”。

## 数据与接口

- `SearchResult.videoMeta` 为可选字段，包含 `author`、`duration`、`views`、`likes`、`favorites`、`comments` 和 Unix 秒级 `publishedAt`；字段随搜索响应、缓存和历史快照透传。
- 引擎元数据新增可选 `credentialUrl`，只返回固定目录中的官方 URL，不返回任何 Secret。

## 验收矩阵

| 场景 | 验收 |
|---|---|
| 引擎管理表格下拉 | 菜单显示在表格和滚动容器之上，选项可点击、键盘可选，滚动/窗口变化后仍贴合按钮。 |
| 通用正文阅读 | 弹窗内容区有圆角；复制正文、重试和打开源站行为保持不变。 |
| B站结果 | 结果有封面时显示封面；点击打开详情，展示可用统计和作者信息；不产生 `/api/fetch-content` 请求；底部没有复制正文按钮。 |
| 凭据配置 | 四个需要/支持凭据的搜索源显示正确申请链接，新窗口打开；输入可切换明文和脱敏；页面不回显已保存 Secret。 |
| 首页来源 | 点击唯一已选来源只显示提示，选择状态不变；仍可通过添加其他来源后取消。 |
| 引擎管理 Tag | 凭据 Tag 可点击并有可见的修改提示。 |

未受影响：B站 412 重试和封面域名校验、其他 Provider 字段、MCP 搜索响应、正文安全校验、Token 与审计数据。
